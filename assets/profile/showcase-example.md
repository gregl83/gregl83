# Project showcase

A preview of selected public engineering projects.

## [Agent Vigilo](https://github.com/agent-vigilo/vigilo)

Isolated WASM evaluators and durable AI evaluation runs.

- [Supporting source](https://github.com/agent-vigilo/vigilo/blob/5a7731c622740c9b986031119b382ebb19e208f6/README.md): Agent Vigilo provides versioned WASM evaluators, durable evaluation runs, worker/coordinator execution, normalized results, and pass/fail gates that can sit in CI or release workflows.
- [Supporting source](https://github.com/agent-vigilo/vigilo/blob/5a7731c622740c9b986031119b382ebb19e208f6/README.md): Wasmtime fuel, memory, timeout, log, and concurrency limits isolate evaluator execution.

## [bazel-paq](https://github.com/gregl83/bazel-paq)

Fingerprint build outputs without changing individual build rules.

- [Supporting source](https://github.com/gregl83/bazel-paq/blob/7f39134ab8662ca7b4706bd24fe33302db7130f8/README.md): `bazel-paq` adds a `.paq` content hash beside each generated directory or file.
- [Supporting source](https://github.com/gregl83/bazel-paq/blob/7f39134ab8662ca7b4706bd24fe33302db7130f8/README.md): No changes to individual build rules are needed.

## [Netband](https://github.com/gregl83/netband)

Track latency under load while bandwidth tests run.

- [Supporting source](https://github.com/gregl83/netband/blob/26cd88d9d4607d7bbdcf3343ad2e175a58b0e650/README.md): continuous monitoring keeps pinging during bandwidth tests and labels the active phase.
